# 총알소녀 — OBT 제출 자료

**팀명**: 7팀 / 유닉온
**게임 제목**: 총알소녀
**장르**: 3-Sort 타워 디펜스 (모바일)
**한줄 소개**: 같은 기물 3개를 정렬해 포탑을 소환하고, 웨이브로 몰려오는 몬스터를 막는 타워 디펜스 게임

---

## 코어 기능

3×3 슬롯 보드에서 같은 기물 3개를 한 슬롯에 모아 정렬(3-Sort)하면 해당 타입의 포탑이 소환된다.
소환된 포탑이 몬스터를 자동 공격하며, 정렬·보충을 반복해 포탑을 유지·교체하면서 스테이지당 10웨이브를 버틴다.
슬롯이 피격으로 파괴되면 정렬로 수리하고, 모든 슬롯이 파괴되면 게임오버. 웨이브 사이 특전을 골라 성장한다.

---

## 구현 기능 목록

### 3-Sort 슬롯 · 게임플로우 · UI/덱 — 이성규

- **[슬롯 보드]** 3×3(9개) 슬롯 보드. 각 슬롯은 셀 3개 보유, 같은 기물 3개 정렬 시 성공 판정
- **[3-Sort 정렬]** 셀 3칸 동일 기물 → 정렬 성공 → 포탑 소환(정상)·수리(파괴 상태) 분기. 성공 후 셀 비우고 보충
- **[기물 보충]** 정렬·소비 후 빈 슬롯에 기물 자동 보충(슬롯당 3칸 중 2칸), 우선순위 배치(동일 2→3→랜덤)
- **[포탑 대기열]** 슬롯당 가동 1 + 대기 1. 가동 파괴 시 대기 승격·발사 시작, 6타입 단위 비주얼 관리
- **[오버소팅]** 가동·대기 모두 찬 상태 추가 정렬 시 잔탄 과열 사격(입력 락) 후 교체
- **[슬롯 파괴·수리]** 슬롯 HP 피격 시 파괴, 파괴 상태 정렬로 수리·부활, 정렬 성공 시 소량 회복
- **[게임오버 판정]** 모든 슬롯 파괴 시 전멸 이벤트 발행(OnAllSlotsDestroyed)
- **[덱 편성]** 보유 카드 6칸 편성/해제(터치·재터치), 6칸 미편성 시 입장 차단 경고
- **[덱 카드 표시]** 초상화·레벨·성급·프레임·배경(기물 6타입별 색) 반영
- **[공용 알림 팝업]** 제목·메시지·확인/취소 팝업(PopupManager·AlertPopup)
- **[아웃게임 UI]** 로비 탭바·덱 편성 화면·팝업 캔버스, 다양한 화면비 대응(CanvasScaler Expand)

### 몬스터 · 포탑 · 전투 — 안정연

- **[몬스터]** 스폰 , 이동·근접 공격, 타입별(일반·속공·탱커) 처리
- **[보스]** 스폰
- **[포탑]** 스폰, 타입별 포탑 데이터 연결, 발사체 풀링
- **[전투]** 타게팅·투사체 발사, 처치 이벤트(경험치·드롭 연결)

### 로그라이크 · 가챠 · 데이터 — 김경민

- **[데이터]** CSV 파싱, SO 자동생성 및 관리 `DataManager` (기반 완료)
- **[로그라이크]** 레벨업·경험치 누적, 특전 선택 흐름(효과 적용은 미구현 — 아래 참조)
- **[스테이지]** 스테이지 진행, 웨이브 관리(`StageManager`)
- **[특전]** 특전 무작위 등장 및 선택, 효과 적용은 아직 미구현.
