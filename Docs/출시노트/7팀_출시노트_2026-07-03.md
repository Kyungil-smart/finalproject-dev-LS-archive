# 출시 노트 양식

> 기간: 2026.07.01(수) ~ 07.10(금)
> Google Play Console 내부 테스트 · 매일 오후 4시까지 업데이트 + 출시 노트
> 운영진이 빌드 + 출시 노트로 진행 상황 확인

---

## 양식 (매일 복붙)

```
v0.9.5 — 7/3

[추가] 
- 관통 투사체 추가
- 튜토리얼 진입 기능 추가(튜토리얼은 미구현)
- 튜토리얼에서 로비 귀환 기능 추가

[UI]
- 언어선택 팝업 UI 동작 구현
- 크레딧 팝업 UI 동작 구현

[수정]
- 노말 투사체 공격대상 선택 수정
- 특전 효과 적용 이벤트 기반으로 수정

[이슈]
- 저격, 힐 투사체 잔존 오류
- EXP시스템 널 엑셉션 오류
- CSV SO 최신화 오류
```

---

## 작성 규칙

- 태그 중 해당 없는 건 생략 (변경 있는 것만)
- 같은 태그에 여러 개면 쉼표로 나열
- 이전 버전 대비 *변경된 내용*만 기록 (운영진이 이걸로 진행 확인)
- 팀 통합 — 세 사람 변경 취합, 이름 표기 생략
- `v0.9.x` 매 빌드 +1 / versionCode도 매번 증가 (충돌 방지)
- 태그는 공지 필수 기록 5종에 대응: 버그 수정·UI/UX·밸런스·리소스·기타 추가/변경

---

## 예시

```
v0.9.2 — 7/1

[추가] 강화 윈도우 UI
[UI] 덱 카드 프레임·배경 색 적용
[수정] 투사체 타겟 소실 오류
```

---

## 운영 메모

- 오후 4시 마감 → 3시쯤 빌드 시작 여유 (versionCode 충돌·빌드 깨짐 대비)
- 빌드 없이 하루 넘기지 말 것 — 변경 작은 날도 빌드 (노트 없으면 진행 0으로 보임)
