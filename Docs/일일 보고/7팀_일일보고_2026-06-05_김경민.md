# 일별 브리핑 양식

> 7팀 플밍 파트 일일 진행상황 브리핑 양식.
>
> **운영 규칙**
> - 오전 작업 시작 전: 팀장이 작업 현황 구글 시트(`7팀_작업_현황`)를 갱신해 기획반에 공유한다.
> - 오전 1교시: 그날의 보고자(= 서기 로테이션)가 본 양식에 맞춰 브리핑을 작성한다.
> - 매일 오전 2교시, 보고 자리에는 팀장 + 보고자가 동행한다.
>
> **보고자 로테이션 순서**
>
> 김경민 → 안정연 → (반복)
>
> 보고자는 팀원 전원의 작업을 받아 작성한다. 팀원은 자기 진척을 말로 보고자에게 전달하고, 글은 보고자(서기)가 일괄 작성한다.
>
> 팀 전체 진척의 정확한 수치·일정은 작업 현황 구글 시트에서 별도로 확인 가능. 이 보고서는 그날 무엇을, 왜, 어디서 막혔는지를 공유하는 용도다.

---

## 사용법

1. 보고 당일에 본 양식을 복사해 새 파일 또는 페이지로 만든다.
2. 파일명: `7팀_일일보고_YYYY-MM-DD_보고자이름.md` 권장.
3. 날짜와 보고자명을 채우고, 각 섹션을 작성한다.
4. 빈 항목은 칸을 지우지 말고 `-` 로 표시한다.
5. 기획팀의 결정·자료가 필요한 항목은 특이사항에 반드시 명시한다.
6. 보고 후 `Docs/일일보고/` 에 저장 후 노션의 일일 보고 공간에 복붙한다.
