# 총알소녀 (가제) — 배포 (Release)

> 3Sort 포탑 소환 디펜스 · 캐주얼 모바일 게임
> 유닉온 기업협약 7팀 프로젝트

같은 기물 3개를 정렬해 포탑을 소환하고, 완성된 포탑으로 몰려오는 몬스터를 막아내는 모바일 3정렬 디펜스 게임입니다. 정렬(3Sort)의 결과가 곧 디펜스 전투의 공격으로 이어집니다.

## 설치·실행 방법 (Google Play)

1. 위 Google Play 테스트 링크에 접속해 테스터 등록을 진행합니다.
2. Play 스토어에서 앱을 설치합니다.
3. 설치된 앱을 실행합니다.

> 세로 모드 고정 게임입니다. 가로로 돌아가지 않습니다.
> 이번 빌드부터 APK 직접 설치가 아닌 Google Play(AAB) 배포입니다. 기기 밀도별 리소스 분할(density split)이 적용되어 다운로드 용량이 줄었습니다.

## 플레이 방법

### 진입 흐름

로비(배틀 탭) → 스테이지 선택 → 덱 편성 → 전투 → 특전 흐름

**인게임 흐름**: 3Sort → 전투 강화 → 웨이브 진행 루프

### 기본 조작

- **드래그** — 기물을 손가락으로 끌어 옮깁니다. (인게임 정렬)
- **탭** — 로비/덱 편성 등 UI는 탭으로 조작합니다.
- **길게 누르기** — 덱 편성 보유 카드를 길게 누르면 상세보기가 열립니다.
- 슬롯의 빈 칸에 기물을 놓으면 배치되고, 찬 칸이나 슬롯 밖에 놓으면 원래 자리로 돌아갑니다.

### 핵심 루프 (인게임)

1. **정렬 (3Sort)** — 한 슬롯 안의 3칸을 *같은 종류 기물 3개*로 채웁니다.
2. **포탑 소환** — 정렬에 성공하면 그 슬롯에 해당 종류의 포탑이 소환됩니다.
3. **디펜스** — 소환된 포탑이 몰려오는 몬스터를 자동으로 공격합니다.
4. **방어** — 몬스터가 슬롯에 도달하면 슬롯의 체력이 깎입니다. 모든 슬롯이 파괴되면 게임 오버입니다.

### 성장 (신규)

1. 로비 **강화** 탭에서 캐릭터를 선택합니다.
2. 미보유 캐릭터는 스타더스트로 **해금**, 보유 캐릭터는 골드로 **강화**합니다.
3. 강화한 레벨이 덱 편성·인게임 전투에 반영됩니다.

### 처음이라면

- 로비 우측의 **? 버튼**으로 튜토리얼을 확인할 수 있습니다.
- **설정 → 언어**에서 한국어/영어/일본어를 선택할 수 있습니다.

## 이전 빌드(OBT) 대비 추가된 부분

OBT 빌드에서 아웃게임 → 덱 편성 → 인게임 전투의 한 흐름과 게임오버 판정까지 완성했고, 이번 배포 빌드에서는 그 위에 **강화·해금(성장 메타) · 스테이지 선택 · 튜토리얼 · 현지화(한/영/일) · 스토어 배포 대응**을 더해 아웃게임을 완결했습니다.

### 아웃게임 / 성장 메타 (신규)

- **강화·해금** — 강화 윈도우에서 캐릭터 해금(스타더스트)과 레벨 강화(골드)를 재화 분리로 처리.<br>강화 결과는 덱 편성·인게임에 즉시 반영.
- **보유·레벨 세이브** — 캐릭터 보유·레벨 상태를 암호화 저장(앱 재실행 후 유지).
- **재화 표시** — 상단 골드·스타더스트 표시. 어느 탭에서 소비해도 즉시 갱신.
- **캐릭터 상세보기** — 카드 길게 누르기로 상세 팝업(스탯·일러스트). 일러스트 감상 모드 토글.
- **정렬(필터)** — 보유 상태 · 공격 유형별 보유 목록 필터.<br>공격 유형 안내 팝업(i 버튼).

### 아웃게임 / 진입 흐름 (신규)

- **스테이지 선택** — 배틀 탭에서 이전/다음 스테이지 순회.<br>일러스트 크로스 슬라이드·배경 크로스페이드 연출. 선택한 스테이지가 인게임 배경에 반영.
- **튜토리얼** — 로비 ? 버튼으로 진입. 페이지 전환 방식으로 조작·규칙 안내(움직이는 예시 화면 포함).
- **설정** — 언어 설정(한국어/영어/일본어)·만든 사람들(크레딧) 팝업.

### 현지화 (신규 · 부분 적용)

- **한/영/일 3개 언어** — 설정에서 전환, 선택 언어 저장·재실행 시 복원.
- **파이프라인** — Google Sheets → Unity Localization 단방향 연동으로 기획팀이 문구를 직접 관리.
- 적용 범위: 설정·언어 팝업, 하단 탭, 스테이지 부제·상단 라벨, 덱 편성 편성/보유 수.<br>일부 화면(강화·상세보기 등)은 미적용 — 아래 한계 참조.

### 인게임 / 조작 (개선)

- **드래그 판정 재설계** — 콜라이더 포함 판정에서 최근접 셀(거리) 판정으로 변경.<br>손가락 오차·기물 가림을 흡수해 조작감 개선, 물리 쿼리 제거.
- **셀 하이라이트** — 드래그 중 놓일 칸을 강조 표시(놓기 판정과 동일 기준).

### UI / 배포 대응

- **세이프 에리어** — 노치·홈 인디케이터 기기에서 상하단 UI가 가려지지 않도록 대응(로비).
- **스토어 배포 설정** — AAB 전환, 기기 밀도 split, Target API 36, ASTC+ETC2 텍스처 압축, 미사용 권한 제거.

### 전투 · 데이터 (팀원 파트)

- ※ 안정연(몬스터·포탑·전투) / 김경민(로그라이크·가챠·데이터) 파트의 OBT 이후 추가분은 당사자 확인 후 기입.

## 리뷰 시 알아두실 점

### 봐주실 포인트

- **아웃게임 완결** — 스테이지 선택 → 덱 편성 → 전투 → 강화로 되돌아오는 성장 순환이 이번 빌드의 핵심 추가분입니다.
- **현지화 파이프라인** — 기획팀 시트 수정만으로 문구가 갱신되는 협업 구조를 확인할 수 있습니다.

### 알려진 이슈 / 한계 (배포)

개발 기간 만료로 이월된 항목입니다. 범위 조절·우선순위 판단의 결과로 남깁니다.

- **현지화 부분 적용** — 강화·상세보기·덱 카드 문구 및 일부 동적 안내 문구는 한국어 고정.<br>일본어 일부 한자 폰트 폴백 검증 필요.
  - 일부 텍스트는 시트 현지화가 미완이라, 연결용 스마트 텍스트(치환 토큰)가 그대로 노출되어 부자연스럽게 보이는 부분이 있습니다.
- **설정 사운드** — 볼륨 슬라이더 UI만 있고 연동 미구현.
- **인게임 상단 UI 세이프 에리어** — 로비만 대응, 인게임(HP·웨이브)은 미적용.
- **미보유·편성 중 카드 길게 누르기** — 일부 상태에서 상세보기가 열리지 않음.
- **성급 해금 선행 조건** — UI만 있고 미적용(재화 비용이 게이트 역할).
- 유저 데이터 연동(클리어 마크·미개척 스테이지 필터 등) 미구현.
