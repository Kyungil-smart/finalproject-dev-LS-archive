## BUG-01. 패배 시 NullReferenceException (모바일)

| 항목 | 내용 |
|---|---|
| 위험도 | **중간** (게임 진행은 되나 패배 경로에서 예외 로그) |
| 발생 환경 | 안드로이드 실기기 전용. Unity 에디터에서는 미재현 |
| 발생 조건 | 인게임 패배(모든 슬롯 파괴) 처리 경로 진입 시 |
| 재현 빈도 | 낮음 (모바일 특정 경로) |
| 현재 상태 | 원인 미확정 (스택트레이스 미확보) |

**상세**
패배 처리 경로에서 NullReference가 발생합니다. 에디터에서는 정상 동작하고 실기기에서만 재현됩니다.

**원인 후보 (미확정)**
- WaveFailHandler의 RewardManager 참조
- SpawnPoint.DeadEvent의 `_target` null
- FindFirstObjectByType 초기화 순서

**시도한 해결 / 이월 사유**
스택트레이스를 확보하지 못해 원인을 특정하지 못했습니다. 배포 후 실기기 logcat으로 스택트레이스를 확보한 뒤 처리 예정입니다. Known-issue로 관리합니다.

## BUG-02. 현지화 스마트 텍스트 토큰 노출

| 항목 | 내용 |
|---|---|
| 위험도 | **중간** (일부 화면 문구 부자연) |
| 발생 환경 | 전 플랫폼 |
| 발생 조건 | 시트 현지화가 미완인 텍스트 표시 시 |
| 재현 빈도 | 항상 (해당 화면 진입 시) |
| 현재 상태 | 이월 (시트 작업 대기) |

**상세**
일부 텍스트는 시트 현지화가 미완이라, 연결용 스마트 텍스트(치환 토큰)가 그대로 노출되어 부자연스럽게 보입니다. 강화·상세보기·덱 카드 문구 및 일부 동적 안내 문구가 한국어로 고정되어 있습니다.

**시도한 해결 / 이월 사유**
파이프라인(Google Sheets → Unity Localization)과 코드측 연결은 완료했으나, 기획팀 시트 엔트리 작성이 미완인 구간이 남았습니다. 시트가 채워지면 코드 수정 없이 해소됩니다.

## BUG-03. 일본어 한자 폰트 폴백 미검증

| 항목 | 내용 |
|---|---|
| 위험도 | **낮음** (일본어 선택 시 일부 글리프 누락 가능) |
| 발생 환경 | 일본어 언어 설정 |
| 발생 조건 | Kazesawa & NotoSansKR 폴백에 없는 일본어 한자 표시 시 |
| 재현 빈도 | 미확인 (검증 미완) |
| 현재 상태 | 이월 (검증 필요) |

**상세**
TMP 폰트 폴백을 `Kazesawa & NotoSansKR`로 설정했으나, 일본어 전용 한자 글리프 커버리지를 전수 검증하지 못했습니다. 누락 시 해당 글자가 표시되지 않을 수 있습니다.

**시도한 해결 / 이월 사유**
한/영 우선으로 폴백을 구성했고, 일본어 글리프 검증은 시간 제약으로 이월했습니다. 일본어 폰트를 폴백 체인에 추가하면 해소됩니다.

## BUG-04. 인게임 상단 UI 세이프 에리어 미적용

| 항목 | 내용 |
|---|---|
| 위험도 | **낮음** (노치 기기에서 상단 UI 일부 가림) |
| 발생 환경 | 노치·펀치홀 안드로이드 기기, 인게임 씬 |
| 발생 조건 | 인게임 진입 (HP·웨이브 표시가 상단 노치 영역과 겹침) |
| 재현 빈도 | 항상 (해당 기기) |
| 현재 상태 | 이월 (로비만 대응 완료) |

**상세**
세이프 에리어 대응을 로비 씬에만 적용했습니다. 인게임 씬 상단 UI(HP·웨이브)는 미적용이라 노치 기기에서 겹칠 수 있습니다.

**시도한 해결 / 이월 사유**
로비용 `SafeAreaOffset`·`SafeAreaFitter`는 계층 변경 없이 부착 가능한 구조로 완성했습니다. 인게임 씬 상단 UI에 동일 컴포넌트를 부착하면 해소되나, 우선순위상 이월했습니다.

## BUG-05. 미보유·편성 중 카드 롱프레스 상세보기 미동작

| 항목 | 내용 |
|---|---|
| 위험도 | **낮음** (일부 상태에서 상세보기 안 열림) |
| 발생 환경 | 전 플랫폼, 덱 편성 화면 |
| 발생 조건 | 미보유 카드 또는 편성 중인 카드를 길게 누를 때 |
| 재현 빈도 | 항상 (해당 카드 상태) |
| 현재 상태 | 이월 |

**상세**
덱 편성에서 미보유·편성 중 상태 카드는 상단 딤이 Raycast를 흡수해 롱프레스 상세보기가 열리지 않습니다.

**시도한 해결 / 이월 사유**
보유·미편성 카드의 롱프레스는 정상 동작합니다. 딤의 Raycast 처리 순서 조정이 필요하나 이월했습니다.

## BUG-06. 설정 사운드 볼륨 슬라이더 미연동

| 항목 | 내용 |
|---|---|
| 위험도 | **낮음** (기능 미구현, 오작동 아님) |
| 발생 환경 | 전 플랫폼, 설정 창 |
| 발생 조건 | 설정 창 볼륨 슬라이더 조작 시 실제 볼륨 미변화 |
| 재현 빈도 | 항상 |
| 현재 상태 | 이월 (UI만 존재) |

**상세**
설정 창의 볼륨 슬라이더 UI는 배치되어 있으나 실제 사운드 볼륨과 연동되지 않았습니다.

**시도한 해결 / 이월 사유**
UI 배치까지 완료, 오디오 믹서 연동은 이월했습니다.
