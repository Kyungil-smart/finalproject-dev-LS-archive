# 총알소녀 (가제) — OBT

> 3Sort 포탑 소환 디펜스 · 캐주얼 모바일 게임
> 유닉온 기업협약 7팀 프로젝트

같은 기물 3개를 정렬해 포탑을 소환하고, 완성된 포탑으로 몰려오는 몬스터를 막아내는 모바일 3정렬 디펜스 게임입니다. 정렬(3Sort)의 결과가 곧 디펜스 전투의 공격으로 이어집니다.

## 이전 빌드(CBT) 대비 추가된 부분

CBT 빌드에서 아웃게임(로비)·덱 편성·인게임 전투의 한 흐름을 붙였고, 이번 OBT 빌드에서는 그 위에 **덱 편성 폴리싱·게임오버 판정·공용 UI 시스템·해상도 대응**을 더해 완성도를 높였습니다.

### 아웃게임 / 덱 편성 (폴리싱·추가)
- **덱 카드 비주얼** — 초상화·레벨·성급에 더해, 기물 타입(6종)별 카드 프레임·배경 색 반영.
- **보유 카드 재터치 해제** — 보유 목록에서 편성된 카드를 다시 탭하면 해제(편성 영역 탭 해제와 별개로 동작).
- **덱 미편성 경고** — 6칸을 모두 채우지 않고 시작하면 경고 팝업으로 입장을 막음(빈 칸 자동 채움 제거).
- **공용 알림 팝업** — 제목·메시지·확인/취소 팝업 시스템(PopupManager·AlertPopup). 강화·설정 등 재사용 대비.

### 인게임 / 게임 플로우 (추가)
- **게임오버 판정** — 모든 슬롯이 파괴되면 전멸 이벤트 발행(패배 처리 연결은 다음 단계).
- **가동 승격 시 발사 시작** — 대기 포탑은 발사하지 않고, 가동으로 승격되는 순간 발사 시작(대기 포탑 오발사 개선).

### UI / 빌드 (개선)
- **해상도 대응** — 로비 UI를 다양한 화면비에서 잘림 없이 표시(CanvasScaler Screen Match Mode를 Expand로).
- **Android 권한 정리** — 사용하지 않는 권한(알림·포그라운드 서비스 계열) 제거.

### 인게임 / 시스템 (CBT에서 정식화)
- **슬롯 데이터 구조 정식화** — 슬롯 체력·회복·부활 등 기획값을 데이터(SlotData)로 관리.
- **슬롯 파괴·부활** — 슬롯이 파괴되면 비활성, 정렬 성공을 쌓아 부활.
- **기물 보충 우선순위** — 빈 슬롯을 채울 때 정렬 가능성을 고려한 우선순위 배치.
- **타워 연결 정식화** — 기물이 연결된 포탑 종류로 슬롯 비주얼이 바뀌도록 타워 데이터와 연결.

### 데이터 및 스테이지
- 데이터 매니저 자동화 및 파싱
- 특전 무작위 선택 및 UI 구현
- 스테이지 — 스테이지 생명주기

### 포탑 및 몬스터(전투 시스템)
- 몬스터 / 포탑 전투 추가분 — 몬스터 종류 및 데이터 연결

## 플레이 방법

### 진입 흐름
로비 - 맵 - 전투 - 특전 흐름

**인게임 흐름**: 3Sort - 전투 강화 - 웨이브 진행 루프

### 기본 조작
- **드래그** — 기물을 손가락으로 끌어 옮깁니다. (인게임 정렬)
- **탭** — 로비/덱 편성 등 UI는 탭으로 조작합니다.
- 슬롯의 빈 칸에 기물을 놓으면 배치되고, 찬 칸이나 슬롯 밖에 놓으면 원래 자리로 돌아갑니다.

### 핵심 루프 (인게임)
1. **정렬 (3Sort)** — 한 슬롯 안의 3칸을 *같은 종류 기물 3개*로 채웁니다.
2. **포탑 소환** — 정렬에 성공하면 그 슬롯에 해당 종류의 포탑이 소환됩니다.
3. **디펜스** — 소환된 포탑이 몰려오는 몬스터를 자동으로 공격합니다.
4. **방어** — 몬스터가 슬롯에 도달하면 슬롯의 체력이 깎입니다. 모든 슬롯이 파괴되면 게임 오버입니다.

### 덱 편성 (신규)
1. 로비에서 **덱 편성** 탭을 엽니다.
2. 보유한 기물을 탭하면 편성 슬롯(6칸)에 들어갑니다. 편성된 기물을 다시 탭하면 해제됩니다.
3. 편성한 덱으로 전투를 시작하면, 그 구성이 인게임 기물 풀에 반영됩니다.

## 리뷰 시 알아두실 점

빌드를 플레이하실 때 알아두면 좋은 점과, 인지하고 있는 한계입니다.

### 봐주실 포인트
- **메타 → 전투 연결** — 로비에서 편성한 덱이 인게임 전투에 반영되는 흐름이 이번 빌드의 핵심 추가분입니다.
- **핵심 전투 루프** — 정렬 → 포탑 → 전투 → 방어는 데모부터 이어지는 핵심 재미입니다.

### 알려진 이슈 / 한계 (OBT)

- **세부 비주얼 후순위** — 덱 편성 등 일부 UI는 골격·동작 우선으로 구현했고, 일부 세부 연출(미보유 카드 표시·정렬/정보 버튼 동작)은 후순위입니다. OBT는 *동작 확인*에 중점을 뒀습니다.
- **튜토리얼 미개발** — 작업자 컨디션 문제로 이번 빌드에 포함하지 못했으며, **다음 빌드에 포함 예정**입니다.
- **강화·설정 화면** — 탭은 있으나 내부 UI는 다음 빌드에 구현 예정.
- 슬롯의 포탑 관련 비주얼 정보 추가 예정
- 게임오버 판정은 구현됐으나, 패배 화면·결과 처리 연결은 다음 단계
- 웨이브 데이터 적용이 아직 안 되어 몬스터가 한 종류 — 추후 확장 예정
- 스테이지 세분화 미구현
- 특전 선택 시 효과 미구현
- 정식 데이터(CSV) 연동 후 밸런스 수치 적용 예정
- 일부 화면(배틀 메인 등)·극단적 화면비의 UI 폴리싱 추가 예정
