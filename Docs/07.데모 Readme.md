# 총알소녀 (가제)

> 3Sort 포탑 소환 디펜스 · 캐주얼 모바일 게임
> 유닉온 기업협약 7팀 프로젝트

같은 기물 3개를 정렬해 포탑을 소환하고, 완성된 포탑으로 몰려오는 몬스터를 막아내는 모바일 3정렬 디펜스 게임입니다. 정렬(3Sort)의 결과가 곧 디펜스 전투의 공격으로 이어집니다.

## 플레이 방법

### 기본 조작

- **드래그** — 기물을 손가락으로 끌어 옮깁니다.
- 슬롯의 빈 칸에 기물을 놓으면 배치되고, 찬 칸이나 슬롯 밖에 놓으면 원래 자리로 돌아갑니다.

### 핵심 루프

1. **정렬 (3Sort)** — 한 슬롯 안의 3칸을 *같은 종류 기물 3개*로 채웁니다.
2. **포탑 소환** — 정렬에 성공하면 그 슬롯에 해당 종류의 포탑이 소환됩니다.
3. **디펜스** — 소환된 포탑이 몰려오는 몬스터를 자동으로 공격합니다.
4. **방어** — 몬스터가 슬롯에 도달하면 슬롯의 체력이 깎입니다. 모든 슬롯이 파괴되면 게임 오버입니다.

### 화면 구성

- **3×3 슬롯 보드** — 9개의 슬롯, 각 슬롯은 3칸. 화면 해상도에 맞게 자동 배치됩니다.
- **슬롯 체력 바** — 각 슬롯 위에 표시. 몬스터에게 공격받으면 줄어듭니다.

### 씬 구성

빌드에는 두 개의 씬이 있고, 화면의 전환 버튼으로 오갈 수 있습니다.

- **인게임 씬** (시작 씬) — 전투 포함. 정렬 → 포탑 소환 → 몬스터 전투 → 슬롯 방어의 핵심 루프를 확인할 수 있습니다.
- **보드 씬** — 전투 없이 슬롯 정렬(3Sort)만 가능. 정렬·드래그·보충 동작을 차분히 확인하기 좋습니다.

## 알려진 이슈 (데모)

데모 빌드에 남아있는 한계로, 인지하고 있으며 데모 이후 정리 예정입니다.

- **슬롯 파괴 시 기물 사용 불가** — 슬롯이 파괴되면 임시 연출로 비활성화되면서 그 슬롯에 있던 기물도 함께 사용할 수 없게 됩니다. 해당 기물이 필요한 정렬(3Sort)을 완성하지 못하는 상황이 생길 수 있습니다.
- **디버그(OnGUI) 표시 위치** — 화면에 표시되는 디버그 정보(대기 그룹·셀 상태)는 검증용 임시 표시라, 일부 해상도에서 위치·크기가 어긋날 수 있습니다.
- **해상도 기준** — 레이아웃을 갤럭시 S23 Ultra(1440×3088) 기준으로 잡았습니다. 슬롯보드는 화면폭에 맞춰 자동 배치되지만, 화면비가 크게 다른 다른 기기에서는 여백·배치가 기준 기기만큼 맞지 않을 수 있습니다.
