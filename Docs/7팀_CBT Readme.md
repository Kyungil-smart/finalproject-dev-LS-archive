# 총알소녀 (가제) — CBT

> 3Sort 포탑 소환 디펜스 · 캐주얼 모바일 게임
> 유닉온 기업협약 7팀 프로젝트

같은 기물 3개를 정렬해 포탑을 소환하고, 완성된 포탑으로 몰려오는 몬스터를 막아내는 모바일 3정렬 디펜스 게임입니다. 정렬(3Sort)의 결과가 곧 디펜스 전투의 공격으로 이어집니다.

## 이전 빌드(데모) 대비 추가된 부분

데모는 핵심 전투 루프(정렬 → 포탑 소환 → 전투 → 방어)만 확인 가능한 빌드였고, 메타 진행 시스템(덱 편성·로그라이크·스테이지)은 *CBT 단계 구현 예정*으로 남겨뒀습니다. 이번 CBT 빌드에서 그 메타 진행을 붙여 **아웃게임(로비) → 덱 편성 → 인게임 전투**의 한 흐름을 확인할 수 있습니다.

### 아웃게임 / 메타 진행 (신규)
- **로비 화면** — 배틀·덱 편성·강화·설정 탭으로 구성된 아웃게임 메인. 탭으로 화면 전환.
- **덱 편성** — 보유 기물을 6칸에 편성(탭으로 선택/해제). 편성한 덱이 인게임 전투에 투입됩니다.
- **씬 흐름** — 로비에서 덱을 편성하고 시작하면, 그 덱 구성으로 인게임 전투에 진입합니다.

### 인게임 / 시스템 (데모 이후 정식화·추가)
- **슬롯 데이터 구조 정식화** — 슬롯 체력·회복·부활 등 기획값을 데이터(SlotData)로 관리.
- **슬롯 파괴·부활** — 슬롯이 파괴되면 비활성, 정렬 성공을 쌓아 부활(데모의 *파괴 시 기물 사용 불가* 이슈 관련 개선).
- **기물 보충 우선순위** — 빈 슬롯을 채울 때 정렬 가능성을 고려한 우선순위 배치.
- **타워 연결 정식화** — 기물이 연결된 포탑 종류로 슬롯 비주얼이 바뀌도록 타워 데이터와 연결.

### 데이터 및 스테이지
- 데이터 매니저 자동화 및 파싱
- 특전 무작위 선택 및 UI 구현
- 스테이지 — 스테이지 생명주기

### 포탑 및 몬스터(전투 시스템)
- 몬스터 / 포탑 전투 추가분 — 몬스터 종류 및 데이터 연결

## 플레이 방법

### 진입 흐름
로비 - 맵 - 전투 - 특전 흐름

**인게임 흐름**: 3Sort - 전투 강화 - 웨이브 진행 루프

### 기본 조작
- **드래그** — 기물을 손가락으로 끌어 옮깁니다. (인게임 정렬)
- **탭** — 로비/덱 편성 등 UI는 탭으로 조작합니다.
- 슬롯의 빈 칸에 기물을 놓으면 배치되고, 찬 칸이나 슬롯 밖에 놓으면 원래 자리로 돌아갑니다.

### 핵심 루프 (인게임)
1. **정렬 (3Sort)** — 한 슬롯 안의 3칸을 *같은 종류 기물 3개*로 채웁니다.
2. **포탑 소환** — 정렬에 성공하면 그 슬롯에 해당 종류의 포탑이 소환됩니다.
3. **디펜스** — 소환된 포탑이 몰려오는 몬스터를 자동으로 공격합니다.
4. **방어** — 몬스터가 슬롯에 도달하면 슬롯의 체력이 깎입니다. 모든 슬롯이 파괴되면 게임 오버입니다.

### 덱 편성 (신규)
1. 로비에서 **덱 편성** 탭을 엽니다.
2. 보유한 기물을 탭하면 편성 슬롯(6칸)에 들어갑니다. 편성된 기물을 다시 탭하면 해제됩니다.
3. 편성한 덱으로 전투를 시작하면, 그 구성이 인게임 기물 풀에 반영됩니다.

## 리뷰 시 알아두실 점

빌드를 플레이하실 때 알아두면 좋은 점과, 인지하고 있는 한계입니다.

### 봐주실 포인트
- **메타 → 전투 연결** — 로비에서 편성한 덱이 인게임 전투에 반영되는 흐름이 이번 빌드의 핵심 추가분입니다.
- **핵심 전투 루프** — 정렬 → 포탑 → 전투 → 방어는 데모부터 이어지는 핵심 재미입니다.

### 알려진 이슈 / 한계 (CBT)

- **세부 비주얼 후순위** — 덱 편성 등 일부 UI는 골격·동작 우선으로 구현했고, 세부 연출(미보유 표시·정렬 버튼·등급 테두리 등)은 후순위입니다. CBT는 *동작 확인*에 중점을 뒀습니다.
- 슬롯의 포탑 관련 비주얼 정보 추가 예정
- 덱편성 보유카드 해상도 이슈: 일부 기기에서 보유 카드가 스크롤 영역을 벗어날 수 있음 - 추후 수정 예정
- 투사체 타겟 잃었을시 탄환이 화면에 남는 문제
- 웨이브 데이터 적용이 아직 안되어 몬스터가 한종류 - 추후 확장 예정
- 스테이지 세분화 미구현
- 특전 선택시 효과 미구현
- UI 폴리싱 작업 및 해상도 대응
